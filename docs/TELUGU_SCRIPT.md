## Pronunciation notes
- Gate codes are read like staff say them: B12 → "బీ పన్నెండు"; flight numbers digit by digit, or the airline name instead (ఎయిర్ ఇండియా, ఖతార్ ఎయిర్‌వేస్).
- Every sentence end is a 0.65 s pause and every comma 0.35 s, inserted by code, so the voice never runs words together.
- Spark's free-form replies (NEED_HELP, BAGGAGE_PROBLEM, OTHER) follow the writing rules in `prompts/parent_turn.md`: spoken register, no calques (no దశ/అడుగు for "step"), board words in English capitals.
